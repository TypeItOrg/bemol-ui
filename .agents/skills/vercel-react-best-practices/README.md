# React performance references

This is a locally adapted copy of Vercel's React performance guidance.

- [SKILL.md](SKILL.md) defines when the skill applies and Bemol's architecture boundaries.
- [REFERENCE.md](REFERENCE.md) indexes the individual files under `rules/`.
- Update a rule in its own file. The index contains links, not a second copy of rule prose.
- This installed package does not include the upstream build or evaluation scripts. Do not run the application's `pnpm build` to regenerate these references.

Upstream: [Vercel agent skills](https://github.com/vercel-labs/agent-skills). Local customizations are intentional; compare upstream updates before replacing them.
